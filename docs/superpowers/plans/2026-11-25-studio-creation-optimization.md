# 创作工作台与 AI 提交优化

**目标** 让创作页专注于任务配置与提交，首页统一展示生成结果，为 AI 调用提供可预检和安全重试的请求格式。

## 创作和首页

- 创作桌面使用双栏，提示词与参数都有独立滚动。窄屏只保留提示词与参数两个页签。
- 工作流、配方、参考图、快捷键、生成按钮及任务调度沿用现有入口。
- 首页复用已有实时画布，预览当前运行任务的新成图及进度。任务切换时防止上一个任务的请求覆盖结果，任务结束后更新最近作品。空闲时沿用最近作品视图。
- 回归覆盖首页运行与空闲切换、创作页布局契约及浏览器的桌面和窄屏交互。

## AI 提交

- 保留 CLI 现有参数，新增 UTF-8 JSON 文件及本地预检模式。标准请求明确正负提示词、工作流参数和幂等请求 ID。
- 使用现有 API 和鉴权，不更改任务生成、入库及队列契约。预检不创建任务、不请求网络、不回显提示词或凭据。
- 使用 CLI 单测、现有后端 Agent 契约测试、前端构建和回归核对结果。
