# DESIGN.md —— AI 图库 / 图像生成工作台（深色 · ComfyUI 气质）

> 用法：把本文件作为 `DESIGN.md` 放到项目根目录，或整段粘贴给任意 AI 编码助手 / AI 建站工具，并说：
> **“严格按照这份 DESIGN.md 实现界面，先做整体框架，再逐个组件落地。”**
> 本规范由 Runway 的深色电影感 + Pinterest 瀑布流 + ComfyUI 工作台面板融合而成。

---

## 0. 产品定位（先让 AI 知道在做什么）

- 这是一个 **AI 图像生成 + 图库浏览的工作台（Web App）**，气质对标 ComfyUI / Runway：深色、专业、工具感强、图片是绝对主角。
- 三个核心区域：**左侧生成控制台（参数面板）｜中间图片瀑布流画布｜右侧图片详情（可折叠）**，顶部一条精简工具栏。
- 整体是“暗色工作台”，不是营销落地页：信息密度偏高、控件规整、留白克制、界面尽量隐入，让生成的图片本身占据视觉中心。
- 所有视觉精致感来自**图片内容、精细的层级、对齐和冷色微差**，不来自彩色渐变背景或花哨装饰。

---

## 1. 视觉主题与氛围

- **暗色电影感工作台**：近黑画布 + 冷灰中性色 + 单一克制的靛蓝强调色（仅用于可交互主操作与选中态）。
- **界面隐身**：零装饰渐变、零厚重阴影；层级靠背景明度差与 1px 描边表达。
- **图片即设计**：色彩与视觉丰富度全部来自生成的图片；界面本身近乎无色。
- **冷调**：中性色统一偏冷（蓝灰），不用暖灰、米黄。
- **专业工具感**：紧凑的间距、等宽字体显示数字与参数、规整的面板分区，像一台“图像生产仪器”。

## 2. 色板与语义角色

### 背景 / 表面（深色优先）
| 名称 | Hex | 用途 |
|---|---|---|
| `canvas` | `#000000` | 应用最深处：主画布 / 网格背景 |
| `bg-base` | `#0a0a0b` | 页面底 |
| `surface` | `#141416` | 侧栏、面板、顶栏底色 |
| `surface-raised` | `#1a1a1d` | 卡片、输入框、按钮、下拉浮层 |
| `surface-hover` | `#232327` | 控件 hover / 行 hover |
| `surface-selected` | `#20222b` | 选中面板 / 激活行（带 accent 倾向） |

### 描边
| 名称 | Hex | 用途 |
|---|---|---|
| `border` | `#27272a` | 默认 1px 描边（几乎不抢戏） |
| `border-strong` | `#3a3a42` | 输入框、分隔强调 |
| `border-focus` | `#5b6cff` | 输入框 / 控件聚焦时的描边 |

### 文字
| 名称 | Hex | 用途 |
|---|---|---|
| `text-primary` | `#f5f6f7` | 标题、主要正文 |
| `text-secondary` | `#a7a7a7` | 次正文、表单标签 |
| `text-muted` | `#767d88` | 占位、说明、时间戳 |
| `text-disabled` | `#555c66` | 禁用态 |

### 功能色（冷调，克制使用）
| 名称 | Hex | 用途 |
|---|---|---|
| `accent` | `#5b6cff` | 主操作按钮（生成）、选中、焦点、关键链接 |
| `accent-hover` | `#6d7cff` | 主按钮 hover |
| `accent-press` | `#4656e8` | 主按钮按下 |
| `accent-soft` | `rgba(91,108,255,.15)` | 选中行 / 标签的浅底 |
| `on-accent` | `#ffffff` | accent 上的文字 |
| `progress` | `#22d3ee` | 生成中进度条 / 队列 / 数据流动 |
| `success` | `#34d399` | 完成、成功状态 |
| `warning` | `#f5a524` | 警告、额度不足 |
| `danger` | `#f45063` | 删除、报错、失败 |
| `node-line` | `#5b6cff` | 节点连线（默认）；激活数据用 `#22d3ee` |

> 规则：除主按钮、选中、进度、状态徽章外，**不要出现任何彩色块**。禁止紫蓝渐变背景、禁止彩色大面积铺底。

## 3. 字体规则

- **UI 正文字体（单一字族）**：`Inter`，回退 `'Inter', system-ui, -apple-system, 'Segoe UI', sans-serif`。
- **等宽字体（数字 / 参数 / 种子 / 代码 / 尺寸）**：`'JetBrains Mono', ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`。所有数值、seed、分辨率、耗时一律用等宽字体。

| 角色 | 字号 | 字重 | 行高 | 字距 | 备注 |
|---|---|---|---|---|---|
| 大标题 / 空状态 | 36–48px | 400 | 1.05 | -1.0px | 紧凑、电影片名感 |
| 区块标题 | 24px | 500 | 1.1 | -0.3px | 面板分组标题 |
| 小标题 | 18–20px | 500 | 1.2 | 0 | 卡片标题 |
| 正文 / 按钮 | 14–16px | 400–500 | 1.4 | -0.15px | 主用 14px |
| 标签 / 表单 label | 12–13px | 500 | 1.3 | 0.35px + 大写 | 分组导航用大写 |
| 辅助 / 时间戳 | 11–12px | 400 | 1.3 | 0 | text-muted |
| 数值 / 代码 | 12–13px | 450–500 | 1.3 | 0 | 等宽字体 |

原则：
- 全应用只一个 sans 字族（Inter），靠字号 / 字重 / 大小写制造层次，不频繁换字体。
- 标题默认负字距、行高 1.0–1.2，营造紧凑专业感。
- 字重范围 400–600，不使用 700+ 粗黑标题。
- 所有数字（尺寸、步数、seed、进度百分比、耗时）必须等宽字体。

## 4. 组件样式

### 按钮
- **主按钮（生成）**：`accent #5b6cff` 填充，`on-accent` 文字，14px 字重 600，圆角 6px，内边距 9px 16px；hover 用 `accent-hover`，按下用 `accent-press`；loading 时左侧出现 14px 旋转 spinner + “生成中…”。
- **次要按钮**：透明底，1px `border-strong`，文字 `text-secondary`；hover 底 `surface-hover`。
- **图标按钮**：32×32 方形、圆角 6px、默认透明，hover 底 `surface-hover`，只放一个线性图标。
- 按钮圆角 6px，**不使用全圆角药丸**（仅小状态标签可胶囊）。

### 输入与控件
- **文本域（Prompt）**：`surface-raised` 底、1px `border`，圆角 8px，内边距 10px 12px，文字 `text-primary`，占位 `text-muted`；聚焦时边框变 `border-focus`，出现 1px 微弱 accent 外发光。
- **滑块（步数 / CFG / 数量）**：轨道高 3px、`#2a2a30`，已滑部分 `accent`，滑块点 12px 实心圆（白或 accent），右侧当前数值用等宽字体。
- **下拉选择（模型 / 比例 / 采样器）**：触发器为 `surface-raised` + 1px 边框；展开浮层为 `surface-raised`，选项 hover `surface-hover`，选中项带 `accent` 小勾与 `accent-soft` 底。
- **开关 / 单选 / 标签**：选中态用 `accent-soft` 底 + `accent` 文字/描边。
- 表单 label 12px、`text-secondary`、大写、字距 0.35px。

### 图片卡片（图库核心）
- 容器圆角 **8px**、`surface-raised` 底，**无边框或仅 1px `border`**，无阴影。
- 图片本身铺满卡片顶部，圆角 8px；加载前用骨架块（`surface-raised` 底 + 微弱扫光）。
- 卡片底部信息层：默认隐藏，hover 时从图片底部升起一层 `linear-gradient(transparent, rgba(0,0,0,.8))`，显示标题、尺寸（等宽）、下载/收藏/“设为参考”三个 28px 图标按钮。
- 左上角小标签：比例或模型（11px 胶囊，`rgba(0,0,0,.55)` 底 + 白字）。
- 选中：卡片外加 2px `accent` 描边；右上角出现 accent 实心对勾。
- **状态遮罩（居中，必须文字+图标双通道，不能只靠颜色）**：
  - 生成中：半透明黑遮罩 + 环形 spinner（`progress`）+ 百分比文字。
  - 队列中：静态时钟图标 + “排队中”。
  - 失败：`danger` 图标 + “生成失败，点击重试”。
- 收藏：未收藏线性空心心，已收藏填充 `#f45063`（或用星形，颜色保持克制）。

### 面板（ComfyUI 式控制台）
- 左侧生成面板宽 **280px**，`surface` 底，右侧 1px `border` 分隔；内部以 12px 间距纵向分组，每组有 12px 大写分组标题。
- 右侧详情面板宽 **320px**，可折叠收起；展示大图预览、完整生成参数（等宽两列对齐）、操作按钮（放大 / 下载 / 收藏 / 重新生成 / 复制 prompt）。
- 分组之间用 1px `border` 分隔线，不要粗分割条。

### 顶栏
- 高 52px，`surface` 底，底部 1px `border`；左侧 Logo + 模型选择，中间视图切换（网格 / 详情 / 节点），右侧“生成”主按钮、额度、用户头像。

### 标签 / 徽章
- 模型、比例、风格标签用小胶囊（圆角 999px），11px，默认 `surface-raised` 底 + `text-secondary`，激活 `accent-soft` + `accent`。

### 浮层
- Tooltip / 下拉 / 模态 / 抽屉：`surface-raised` 底 + 1px `border-strong`；允许极轻阴影 `0 12px 40px rgba(0,0,0,.5)`（仅浮层，页面元素仍零阴影）。
- 模态宽 480–640px，圆角 10px。

### 节点（可选，节点画布视图）
- 节点块：`surface-raised` + 1px `border`，圆角 8px，标题栏 28px 高、`surface-hover` 底、12px 大写标题。
- 端口：左右两侧 8px 圆点；未连接 `#6b7280`，连接后 `accent`。
- 连线：1.5px 贝塞尔曲线，默认 `#5b6cff`，有数据流时 `#22d3ee`。

## 5. 布局原则

- **间距基线 8px**：4 / 6 / 8 / 12 / 16 / 20 / 24 / 32 / 48。
- 面板内部组件间距 12px，分组间距 16–20px；控件紧凑但不拥挤。
- **图片网格 = 瀑布流（masonry）**：
  - 推荐用 CSS `columns`：`column-width: 220px; column-gap: 12px;`，卡片 `break-inside: avoid; margin-bottom: 12px;`。
  - 列宽 200–260px 自适应，卡片间距 12px，卡片圆角 8px。
  - 也可切换成等宽方阵（`grid` 正方形缩略图，每行 4–6 个）用于“批量浏览”。
- 主内容区最大不限宽（工作台占满视口），营销页才用 1200–1600px 居中容器。
- 界面框架：`52px 顶栏 + 280px 左面板 + 弹性网格主区 (+320px 右面板)`。
- 对齐：参数“标签在上、控件在下”，数值右对齐或等宽对齐；同组控件左缘对齐。

---

## 6. 深度与层级

- 页面元素默认**零阴影**，靠背景明度差与 1px 描边区分层级：
  `canvas(#000) → surface(#141416) → surface-raised(#1a1a1d) → hover(#232327)`。
- 仅浮层（下拉、模态、tooltip、抽屉）允许极轻阴影。
- 选中与聚焦统一用 accent 描边 / accent-soft 底，不用彩色投影。
- 图片卡片的悬停层用黑色渐变，不用彩色辉光。

---

## 7. Do / Don’t

### Do
- 用近黑底 + 冷灰中性色，让图片成为唯一的色彩中心。
- accent 靛蓝只用于“生成”主按钮、焦点、选中与进度。
- 数字 / 参数 / seed / 尺寸一律等宽字体。
- 图库用瀑布流，卡片 8px 圆角、12px 间距、hover 浮出操作层。
- 控件用 6–8px 小圆角，描边克制，面板分区规整。
- 所有状态（生成中 / 成功 / 失败 / 排队）同时给图标和文字。
- 保持较高信息密度，像专业生产工具，而不是营销首页。

### Don’t
- 不要紫蓝渐变背景、彩色大面积铺底、彩色辉光（典型 AI 味）。
- 不要全用大圆角药丸按钮；不要卡片套卡片。
- 不要厚重阴影 / 发光描边；不要暖灰、米黄、纯黑文字配彩色底。
- 不要用 700+ 粗黑标题；不要全局正文字重过重。
- 不要把每张图都加边框，让图片自然铺在画布上。
- 不要用颜色单独传达状态（必须配图标 / 文字）。
- 不要在界面里堆装饰性插画 / emoji，工作台保持干净。

## 8. 响应式

| 断点 | 行为 |
|---|---|
| ≥1280px | 三栏完整：左 280 + 网格 + 右 320 |
| 900–1280px | 右侧详情面板改为抽屉；左面板可收起到图标栏 |
| 640–900px | 左面板折叠为底部抽屉或抽屉式“参数”页；瀑布流 2 列 |
| <640px | 单栏；顶栏精简；生成按钮固定底部；网格 2 列、卡片间距 8px |
- 触控目标不小于 40×40px；移动端生成按钮固定底部安全区。
- 瀑布流随宽度从 5 列 → 4 → 3 → 2 自适应。

## 9. 给 AI 的执行提示词（可直接用）

### 一句话总指令
> “用 React + Tailwind（或纯 HTML/CSS）构建一个**深色 AI 图像生成图库工作台**，严格遵循 DESIGN.md：近黑底 + 冷灰 + 单一靛蓝 accent，Inter 字体 + JetBrains Mono 数字；布局为 52px 顶栏、280px 左侧生成控制台、中间图片瀑布流（CSS columns、220px 列宽、12px 间距、8px 圆角卡片）、可折叠 320px 右侧详情面板；零装饰渐变、零重阴影、小圆角，图片是绝对主角。”

### 关键组件 Prompt
- 左侧控制台：`surface #141416` 面板、280px 宽、12px 分组；包含多行 Prompt 文本域（#1a1a1d 底、focus 时 #5b6cff 描边）、负面提示词、模型下拉、比例选择（胶囊标签）、采样步数与 CFG 滑块（已滑部分 accent，数值等宽）、seed 输入（等宽）、生成数量、一个 accent 填充的“生成”主按钮（带 loading 态）。
- 图片卡片：8px 圆角、无边框、masonry 瀑布流；hover 底部升起黑色渐变操作层（下载/收藏/设为参考）；左上比例标签；生成中显示 progress 青色 spinner 与百分比；失败显示 danger 重试；选中为 2px accent 描边 + 对勾。
- 顶栏：52px，左 Logo + 模型，中“网格 / 详情 / 节点”切换，右 accent 生成按钮、额度、头像。
- 右侧详情：选中图后展开，含大图、等宽参数表、放大/下载/重新生成按钮。
- 空状态：48px 紧凑标题 + 一句 text-muted 说明 + 一个线性插画图标（单线条，不用彩色）。

### 验收标准
- 首屏截图整体为深色，最显眼的是图片网格，而不是彩色控件。
- 页面中除 accent 按钮、进度、状态外没有其他彩色。
- 任意数字（步数 / 尺寸 / seed / 百分比 / 耗时）均为等宽字体。
- 瀑布流在不同宽度下卡片等高错位排列、不拉伸图片。
- 所有控件 6–8px 圆角、1px 边框、无重阴影。
