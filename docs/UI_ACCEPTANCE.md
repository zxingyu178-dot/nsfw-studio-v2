- ✅ 全部交互组件（Button / Input / Select / Slider / Switch / Checkbox / Radio / Segmented / Tabs）具备 `:focus-visible` 焦点环（`--focus-ring`）。
- ✅ Drawer / Modal 支持遮罩关闭与关闭按钮，焦点在浮层内循环、关闭后回到触发元素（useOverlay 管理）。
